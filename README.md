# UiDance

Ui Shigure (しぐれうい); dancing in your TempleOS window



https://github.com/user-attachments/assets/9a8fc682-14e1-4336-bb63-4f682109916e



### USAGE

`UiDance;` to begin dancing

`UiStop;` to stop dancing

### INFO

You can download the zip file from [Releases](https://github.com/0x2f22d23e/UiDance/releases) page, which contains a bootable ISO (slipstreamed TempleOS V5.03 w/ UiDance) as well as the standalone ISO.C disk image
